# Portfolio design and content

The current design follows the owner's request for straightforward, practical information: a compact name/header, a short introduction, category filters, and project cards. Large slogans, the animated orbital sculpture, ticker, decorative headings, and promotional contact section have been removed. Project details open in keyboard-dismissible dialogs; supplied screenshots can be viewed in full there.

Colors use a cool dark background and a moderately dark blue accent (`#345f98`), with lighter blue text where contrast requires it. The RK monogram is an original SVG used in the header, admin, and favicon. Motion is limited to short hover transitions and respects reduced-motion preferences.

[projects.md](projects.md) is the supplied source for all six projects. Descriptions have been lightly edited for spelling and readability without adding features, dates, completion claims, or project links. Only acq and My own environment are marked In development because the source explicitly says they are current work. Project years remain editable data but are not displayed because the source did not supply dates.

Images are the owner's supplied originals, self-hosted with descriptive filenames. Project screenshots retain their colors. The photo is cropped only by the card's CSS presentation; the original remains available in its detail dialog. No generated replacement images were used.

Space Grotesk is self-hosted at `static/fonts/space-grotesk.ttf`, with the SIL Open Font License in `static/fonts/OFL.txt`. No external font requests, analytics, or third-party JavaScript execute in visitors' browsers. The earlier design used [Codrops' 3D portfolio work](https://tympanus.net/codrops/2025/01/21/the-journey-of-creating-a-3d-portfolio/) as inspiration; the current compact design supersedes that visual direction.
